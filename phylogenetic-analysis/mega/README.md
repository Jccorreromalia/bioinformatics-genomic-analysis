# MEGA Files

This directory contains files generated and used with MEGA (Molecular Evolutionary Genetics Analysis) software during phylogenetic analysis.

## Contents

- `mega_alignment_2.meg`
  - Alignment/project file used for phylogenetic analysis

- `mega_alignment_2.mtsx`
  - MEGA session/project file

## Applications

These files were used for:

- Sequence alignment visualization
- Evolutionary comparison
- Maximum Likelihood tree generation
- Bootstrap analysis
- Phylogenetic inference
