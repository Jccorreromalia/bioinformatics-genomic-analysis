# Phylogenetic Analysis

This directory contains files related to phylogenetic and evolutionary analysis of the POLR1C gene.

## Contents

### `mega/`
MEGA project and alignment files used for phylogenetic tree generation and evolutionary analysis.

### `alignments/`
Multiple sequence alignment files used during comparative analysis.

## Methods used

- Multiple Sequence Alignment (MSA)
- Maximum Likelihood phylogenetic trees
- Bootstrap analysis
- Comparative evolutionary analysis

## Software

- MEGA (Molecular Evolutionary Genetics Analysis)
- Clustal Omega
