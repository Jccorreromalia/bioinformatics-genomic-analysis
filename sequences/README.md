# Sequences

This directory contains all nucleotide and protein sequences used throughout the comparative genomic analysis of the POLR1C gene associated with Treacher Collins Syndrome.

The sequences were retrieved from public biological databases such as NCBI and UniProt and were used for:

- Orthologue identification
- Multiple sequence alignment (MSA)
- Comparative genomics
- Protein conservation analysis
- Phylogenetic analysis
- Secondary structure prediction

## Directory structure

- `nucleotide/` → nucleotide FASTA sequences
- `protein/` → translated protein FASTA sequences
