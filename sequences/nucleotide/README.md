# Nucleotide Sequences

This directory contains all nucleotide FASTA sequences used in the comparative genomic analysis of the POLR1C gene.

## Contents

- `Homo_sapiens_nucleotide.fa`
  - Human reference nucleotide sequence for POLR1C

- `total_sequences.fa`
  - Multi-FASTA file containing all nucleotide sequences used for multiple sequence alignment and phylogenetic analysis

- `orthologues/`
  - Individual nucleotide orthologue sequences from different mammalian species

## Applications

These sequences were used for:

- Orthologue comparison
- Multiple sequence alignment (MSA)
- Evolutionary conservation analysis
- Phylogenetic tree construction
