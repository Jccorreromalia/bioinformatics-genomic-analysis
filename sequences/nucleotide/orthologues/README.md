# Nucleotide Orthologues

This directory contains nucleotide orthologue sequences of the POLR1C gene from different mammalian species.

The sequences were obtained from NCBI databases and used for comparative genomics and phylogenetic analysis.

## Species included

- Acinonyx jubatus
- Diceros bicornis minor
- Equus quagga
- Hippopotamus amphibius kiboko
- Pan paniscus
- Pan troglodytes
- Panthera leo
- Pongo abelii
- Puma yagouaroundi

## File format

All files are provided in FASTA format (`.fa`).
