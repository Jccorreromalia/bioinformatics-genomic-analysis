# Protein Sequences

This directory contains translated protein sequences corresponding to the POLR1C gene.

## Contents

- `Homo_sapiens_protein.fa`
  - Human POLR1C protein reference sequence

- `total_proteins.fa`
  - Multi-FASTA file containing all protein sequences used for protein multiple sequence alignment

- `orthologues/`
  - Protein orthologues from different mammalian species

## Applications

These protein sequences were used for:

- Protein multiple sequence alignment
- Conserved region identification
- Comparative protein analysis
- Secondary structure prediction
