# Protein Orthologues

This directory contains translated protein orthologues of the POLR1C gene from different mammalian species.

The sequences were used for comparative protein analysis and evolutionary conservation studies.

## Species included

- Acinonyx jubatus
- Diceros bicornis minor
- Equus quagga
- Hippopotamus amphibius kiboko
- Pan paniscus
- Pan troglodytes
- Panthera leo
- Pongo abelii
- Puma yagouaroundi

## File format

All sequences are provided in FASTA format (`.fa`).
