# Raw Reads

Raw sequencing datasets used during this project are not included in this repository due to GitHub file size limitations.

## Sequencing datasets used

- `SRR3137854`
  - Illumina paired-end sequencing reads

- `SRR21079301`
  - Nanopore long-read sequencing dataset

## Applications

These datasets were used for:

- Sequencing quality analysis
- Genome assembly
- Assembly comparison
- Evaluation of sequencing technologies
