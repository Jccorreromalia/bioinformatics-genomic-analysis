# Assembly and Annotation

This directory contains sequencing reads and reference sequences used during genome assembly and quality analysis workflows.

## Contents

### `raw-reads/`

Contains Illumina paired-end sequencing reads used for assembly analysis.

Files:
- `SRR3137854-forward.fastqsanger`
- `SRR31378544-reverse.fastqsanger`

### `bacterial-reference/`

Contains the bacterial reference genome used during assembly evaluation.

Files:
- `Kpneumoniae.fasta`

## Methods and tools used

- FastQC
- MultiQC
- NanoPlot
- SPAdes
- Flye
- QUAST

## Notes

Some raw sequencing files were not uploaded due to GitHub file size limitations.
