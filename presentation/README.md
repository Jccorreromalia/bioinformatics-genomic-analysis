# Presentation

This directory contains the final report and presentation corresponding to the comparative genomic and bioinformatics analysis project focused on the POLR1C gene and Treacher Collins Syndrome.

## Contents

- `comparative_genomic_analysis_report.pdf`

The report includes:

- Genetic disease background
- Orthologue identification
- Multiple sequence alignment (MSA)
- Comparative protein analysis
- Secondary structure prediction
- Phylogenetic analysis
- Genome assembly and annotation workflows
- Sequencing quality analysis
